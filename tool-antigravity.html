主軸二

Antigravity
視覺識別

讓 AI 看懂圖片和文件。上傳 PDF 試卷或拍下學生作業，AI 自動辨識內容、萃取資訊、建立結構化資料。

Gemini Vision PDF 解析 Python Flask 進階工具
這個主軸在做什麼？

讓 AI 的眼睛幫你讀文件

這條路線利用 AI 的視覺能力（Vision）來處理圖片和 PDF 文件。傳統的 OCR 只是把圖片轉成文字，但 Gemini 的視覺 AI 更進一步——它能理解文字的意思、判斷題目類型、修正辨識錯誤，並把資訊整理成結構化的格式。

Antigravity 是這個系統的開發平台，讓你不需要架設伺服器，直接在瀏覽器介面操作整個流程。

⚠️
這個主軸的設定比主軸一複雜， 需要在電腦安裝 Python 環境。建議先熟悉主軸一再來挑戰。沒有時間壓力，想試的時候再來就好。
優點與限制

什麼情況適合？什麼情況不適合？

✦ 適合的地方

  • 大量 PDF 試卷的批次處理
  • 圖文並茂的試卷，圖片和題目自動對應
  • AI 自動修正 OCR 錯誤，理解語意
  • 題庫長期累積，越用越有價值
  • 匯出格式整齊的 Word 試卷
  • 正確處理注音符號，適合國文科

△ 需要注意的地方

  • 需要安裝 Python，有一定技術門檻
  • 掃描圖片 PDF 辨識精準度較低
  • Gemini API 解析有費用（很低但非完全免費）
  • 系統跑在自己電腦，電腦關掉就無法使用

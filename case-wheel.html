轉盤抽籤遊戲

一個 HTML 檔案，不需安裝任何程式，存到 USB 隨時帶著走，在教室裡讓學生轉出今天的挑戰。

Gemini Canvas 開發 純前端 · 零後端 離線可用 免費
這是什麼？

一個轉盤，解決很多小事

這個工具是用 Gemini Canvas（Google 的 AI 程式生成工具）開發的。你只需要用說的，告訴 AI 你想要什麼樣的轉盤，它就會幫你寫好所有程式碼，產出一個完整的 HTML 檔案。

這個檔案可以直接在瀏覽器打開，完全不需要網路、不需要帳號、不需要安裝任何東西。存在桌面、存進 USB 隨身碟，要用就打開。

💡
實際案例：北門國小的老師用它做了「母語轉轉樂」，轉盤上是不同的母語詞彙，學生轉到哪個就練習說哪個，課堂氣氛一下子活躍起來。
優點與限制

什麼情況適合？什麼情況不適合？

每種工具都有它最適合的舞台，也有它不擅長的地方。了解這些，才能用得剛剛好。

✦ 適合的地方

  • 不需要網路，離線也能用
  • 一個檔案就是完整工具，傳給同事超方便
  • 學生看到轉盤會興奮，課堂參與感提升
  • 不需要任何程式知識就能使用
  • 完全免費，沒有使用次數限制
  • 轉盤選項可以依課程內容調整

△ 需要注意的地方

  • 選項內容需要自己輸入，無法自動從名冊匯入
  • 每次關掉瀏覽器，設定就回到預設（需重新選）
  • 如果想修改選項種類，需要請 AI 重新生成
  • 介面語言固定，無法動態切換

這是用什麼工具做的？

Gemini Canvas — 用說的就能寫程式

這個轉盤是用 Google Gemini Canvas 開發的。Gemini Canvas 是 Google AI 的一個功能，你可以用白話文描述你想要的工具，它會直接幫你產生出可以在瀏覽器使用的網頁程式。

怎麼做？

從零開始，做一個自己的轉盤

以下是完整步驟。整個過程大約需要 10–15 分鐘，就算是第一次接觸 AI 工具的老師也可以完成。

📋
開始前需要準備： 一個 Google 帳號（免費）、電腦或平板、瀏覽器（Chrome 最佳）
1

開啟 Gemini Canvas

在瀏覽器網址列輸入 gemini.google.com，用 Google 帳號登入後，點選左側選單的「Canvas」。

如果找不到 Canvas，可以在對話框輸入「請幫我用 Canvas 製作一個轉盤遊戲」，它會自動切換到 Canvas 模式。
Gemini Canvas 入口截圖（待補）
2

用白話文描述你要什麼

在對話框裡輸入你想要的轉盤內容。不需要很正式，就像在跟同事說話一樣。

範例提示詞：
「請幫我製作一個抽籤轉盤，上面有 8 個格子，分別放上這些字：小明、小華、小美、小志、小婷、小杰、小雯、小安。轉盤旋轉後停下來要顯示抽到的名字。請用繁體中文，介面要簡單好看。」
對話框輸入截圖（待補）
3

等 AI 生成，然後預覽

Gemini 會在右側即時產生轉盤，你可以直接在預覽區試轉看看。如果不滿意，繼續在對話框說「請把顏色改成藍色」或「轉速慢一點」，它會馬上修改。

Canvas 預覽截圖（待補）
4

下載 HTML 檔案

滿意之後，點右上角的「匯出」或「下載」按鈕，選擇「下載為 HTML」，檔案就會儲存到你的電腦。

下載後，在電腦上找到這個檔案（通常在「下載」資料夾），用滑鼠雙擊就可以在瀏覽器打開使用，完全不需要網路。
下載按鈕截圖（待補）
5

存進 USB，帶進教室

把這個 .html 檔案複製到 USB 隨身碟或存到 Google 雲端硬碟，下次上課直接打開就可以用了。也可以傳給同事，他們電腦上也能直接使用，不需要安裝任何東西。

遇到問題？

常見疑問

轉盤的選項可以自己改嗎？

可以。回到 Gemini Canvas，在對話框說「把第三個選項改成○○」或「新增一個選項叫做△△」，它就會幫你修改並重新下載。

可以在手機上用嗎？

可以，但建議用電腦操作。手機瀏覽器也能打開 HTML 檔案，但部分功能可能受限，投影在大螢幕效果最好。

需要付費嗎？

Gemini 基本版免費，Canvas 功能也包含在免費方案內。每天有使用次數限制，一般教師使用完全足夠，不需升級付費版。

AI 生成的結果不是我想要的怎麼辦？

繼續在對話框說明你覺得哪裡不對，例如「轉盤格子太小，字看不清楚」或「我想要紅色和黃色交替」。AI 不會因為你一直修改而不耐煩，放心慢慢調整。

看看實際效果

以下是北門國小老師製作的「母語轉轉樂」，點進去可以直接試轉看看，感受一下學生在課堂上玩到這個會有多興奮。

▶ 開啟轉盤遊戲示範
進階：發布到網路

讓任何人都能用網址打開你的轉盤

如果你想把轉盤分享給其他老師或學生，讓他們直接用網址打開，而不需要傳檔案，可以把它免費掛到 GitHub Pages。完成後會得到一個像這樣的網址：

https://你的帳號.github.io/teaching-web/
📋
開始前需要準備： 一個免費的 GitHub 帳號（github.com 註冊）、電腦上已安裝 Node.js 18 以上版本

第一部分：安裝 Claude Code（只需做一次）

1

確認 Node.js 已安裝

按 Win + R，輸入 cmd，按 Enter 開啟命令提示字元，輸入：

node --version
如果看到 v18 以上的版本號，代表已安裝。如果顯示「找不到命令」，請先到 nodejs.org 下載安裝。
2

安裝 Claude Code

在命令提示字元輸入：

npm install -g @anthropic-ai/claude-code
安裝需要約 1–2 分鐘。完成後輸入 claude --version 確認安裝成功。

第二部分：在 GitHub 建立 Repo

3

新增一個 GitHub Repository

登入 github.com，點右上角 ＋ → New repository，填入：

Repository name teaching-web
Visibility 選 Public（免費 GitHub Pages 需要）
Add README ❌ 不要勾選

按 Create repository。

第三部分：用 Claude Code 推上 GitHub

4

建立工作目錄，把檔案放進去

在命令提示字元輸入：

mkdir c:\claude\teaching-web cd c:\claude\teaching-web
然後把你下載的 index.html、case-wheel.html、CLAUDE.md 複製到這個資料夾內。
5

啟動 Claude Code

確認在 c:\claude\teaching-web 目錄後，輸入：

claude
第一次執行會要求你輸入 Anthropic API Key，可到 console.anthropic.com 取得免費額度的 Key。
6

請 Claude Code 幫你推上 GitHub

進入 Claude Code 後，用白話文輸入（把 你的帳號 換成你的 GitHub 帳號）：

請幫我初始化 git，把所有檔案 commit，remote 設定為 https://github.com/你的帳號/teaching-web.git， 然後 push 到 main branch
Claude Code 會自動執行 git init、add、commit、push 等指令。Push 時瀏覽器會彈出 GitHub 登入視窗，登入授權即可。

第四部分：開啟 GitHub Pages

7

在 GitHub 開啟 Pages 功能

到你的 repo 頁面，點 Settings → Pages，在 Branch 選 main，資料夾選 / (root)，按 Save。

GitHub Pages 設定截圖（待補）
等約 1–2 分鐘，頁面上方會出現你的網站網址，格式為 https://你的帳號.github.io/teaching-web/
🎉
完成！ 之後每次新增或修改檔案，在 Claude Code 說「幫我把新檔案 push 到 GitHub」，網站幾分鐘內就會自動更新。

OCR 錯卷
題庫系統

把學生的錯誤試卷掃描上傳，AI 自動辨識題目、分類科目、建成題庫，再匯出成可列印的 Word 試卷。

Python Flask Gemini 2.5 Flash PyMuPDF SQLite 題庫
⚠️
這個案例的設定比前兩個複雜。 需要在電腦上安裝 Python 環境，並在命令列執行指令。如果你是第一次接觸，建議先從「轉盤遊戲」或「LINE 行事曆助理」開始，熟悉了再回來挑戰這個。

沒有時間限制，想試的時候再來就好。
這是什麼？

讓 AI 幫你整理錯誤試卷

這個系統解決一個很具體的問題：學生考完試，老師想把錯誤率高的題目收集起來，出一份「錯題複習卷」，但手動剪貼又慢又累。

現在的流程變成這樣：把 PDF 試卷上傳，AI 自動讀取每一道題目、判斷科目和題型、把題目存進資料庫。之後你可以用篩選器找出特定科目或題型，勾選想要的題目，一鍵匯出成格式整齊的 Word 試卷。

✨
特別能力： AI 會自動修正 OCR 辨識錯誤，還能處理注音符號——如果題目本來就有「ㄞˋ」這樣的注音，它不會擅自翻譯成國字，完整保留原題意。

優點與限制

什麼情況適合？什麼情況不適合？

✦ 適合的地方

  • 大量試卷時節省大量手動整理時間
  • 支援圖文並茂的試卷（圖片會跟著題目一起保留）
  • 題庫會累積，長期使用價值越來越高
  • AI 能正確處理注音符號，國文老師適用
  • 匯出的 Word 格式整齊，不需要再手動排版
  • 程式碼完全公開，可以自行修改調整

△ 需要注意的地方

  • 需要在電腦安裝 Python，對初學者有一定門檻
  • 整頁掃描成圖片的 PDF 辨識精準度較低
  • Gemini API 解析有費用（雖然很低，但不是完全免費）
  • 系統跑在自己電腦，電腦關掉就無法使用
  • 目前僅支援九科國中科目，不含國小課程
📋
哪種 PDF 效果最好？
從 Word 或 Google 文件直接「另存新檔為 PDF」的試卷效果最好，因為文字是可以直接讀取的。
拿紙本試卷用掃描機掃出來的 PDF，整頁會變成一張大圖，AI 可以讀但精準度較低，圖片也無法單獨裁切。

用了哪些技術？

這個系統的組成

Python Flask（後端）
Gemini 2.5 Flash（AI 辨識）
PyMuPDF（PDF 解析）
SQLite（題庫儲存）
python-docx（Word 匯出）
🤔
不懂這些名詞沒關係。 簡單說：Python 是讓程式跑起來的語言，Flask 是讓你在瀏覽器操作的介面，SQLite 是把題目存起來的小型資料庫，其他的都是讓 AI 讀 PDF、寫 Word 用的工具。你不需要懂它們怎麼運作，只需要按照步驟讓它們跑起來。
怎麼開始？

從安裝到第一次使用

整個過程分三個部分。第一次設定約需 20–30 分鐘，之後每次使用只需開啟伺服器就好。

📋
開始前需要準備： Windows 或 Mac 電腦、Google 帳號（取得 Gemini API Key）、約 20 分鐘的時間

第一部分：安裝 Python

1

下載並安裝 Python

前往 python.org/downloads，下載最新版本（3.10 以上），執行安裝程式。

⚠️ 安裝時有一個選項非常重要：「Add Python to PATH」 務必勾選，否則之後的步驟會失敗。勾選後再點 Install Now。
Python 安裝勾選 PATH 截圖（待補）
2

確認安裝成功

按 Win + R，輸入 cmd，按 Enter，在黑色視窗輸入：

python --version
看到 Python 3.x.x 就代表安裝成功。

第二部分：下載並啟動系統

3

下載程式碼

前往 GitHub repo，點綠色的 Code → Download ZIP，解壓縮到你熟悉的資料夾（例如桌面）。

GitHub 下載 ZIP 截圖（待補）
4

安裝所需套件

打開命令提示字元（cmd），切換到剛才解壓縮的資料夾，輸入：

cd 你的資料夾路徑 pip install -r requirements.txt
這個步驟會安裝 Flask、PyMuPDF 等工具，需要幾分鐘，看到畫面停下來就代表完成。
5

啟動伺服器

在同一個命令提示字元視窗輸入：

python app.py

看到這行訊息就代表系統啟動成功：

[OK] System started: http://127.0.0.1:5000
這個黑色視窗要保持開著，關掉的話系統就會停止。之後使用只需要重複這個步驟。
6

在瀏覽器開啟

打開 Chrome 或 Edge，在網址列輸入：

http://127.0.0.1:5000

你應該會看到系統的操作介面。

系統首頁截圖（待補）

第三部分：第一次使用

7

填入 Gemini API Key

在系統左側選單找到「API 設定」，填入你的 Gemini API Key（取得方式請參考 LINE 行事曆助理的步驟 1–2）。

Key 只存在你的瀏覽器，不會傳到其他地方，關掉瀏覽器下次需要重新填。
8

上傳第一份 PDF 試卷

點「上傳 PDF」，選擇一份試卷（建議先用電子檔 PDF 測試，效果最好）。系統會在背景處理，完成後題目會出現在題庫列表。

篩選、勾選、匯出

在題庫列表用科目、題型篩選，勾選想要的題目，填入試卷標題，點「匯出 Word」。瀏覽器會自動下載一個格式整齊的 .docx 試卷。

遇到問題？

常見疑問

pip install 安裝失敗怎麼辦？

最常見原因是 Python 安裝時沒有勾選「Add to PATH」。解決方式：重新安裝 Python，這次記得勾選那個選項。

上傳後很久沒有反應？

Gemini 解析 PDF 需要時間，通常 10–30 秒，較大的檔案可能需要 1–2 分鐘。頁面上有進度顯示，可以等一下再看。

題目解析結果不正確？

通常是 PDF 本身是掃描圖片，文字識別率較低。可以把有問題的題目刪除，用電子檔 PDF 重新試試。AI 偶爾也會判斷錯題型，在題庫裡直接刪除那道題再手動調整就好。

題庫的資料存在哪裡？

存在程式資料夾裡的 question_bank.db 檔案。只要這個檔案還在，題庫資料就不會消失。建議偶爾備份一下這個檔案。

資安確認

這個工具安全嗎？

✓ API Key 由前端傳入，不硬編碼在程式裡，不會出現在 GitHub repo
✓ .env 和資料庫檔案（.db）已加入 .gitignore，不會被上傳到 GitHub
✓ 系統只跑在你自己的電腦（127.0.0.1），外網無法存取
△ 目前設定為 debug=True + host="0.0.0.0"，若要在學校網路環境部署請修改為 debug=False, host="127.0.0.1"
△ uploads/ 資料夾建議確認未暴露在公開路由下
△ 部分 SQL 查詢使用 f-string，建議改為參數化查詢（進階使用者）
🔒
只在自己的電腦使用就很安全。 如果你想部署到學校伺服器讓其他老師也能用，請先修正上方的三個中風險項目，或聯繫有資訊背景的同事協助確認。

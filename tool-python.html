主軸五

Python
本地工具

在自己的電腦上跑，學生資料不離開本機，沒有月費，也不需要雲端帳號。適合流程固定、重複性高、又需要深度客製的教學任務。

Python Flask 本地介面 瀏覽器自動化 資料完全在本機
這個主軸在做什麼？

讓程式幫你做重複的事，資料留在自己手裡

這條路線的核心思路是：把你每次要重複做的操作，寫成程式讓它自動執行。你只需要設定一次，之後按一個鍵，程式就會照步驟把事情做完。

和其他主軸最大的不同在於，這裡的工具全部跑在你自己的電腦上。沒有 Google 試算表、沒有 LINE Bot、沒有任何外部平台——程式直接開啟瀏覽器、讀取檔案、寫入資料庫，一切在本機完成。

⚠️
這是四個主軸裡門檻最高的。 需要在電腦安裝 Python，第一次設定需要 30–60 分鐘。如果你是第一次接觸 AI 工具，建議先從主軸一（GAS + Gemini）或主軸三（Canvas 純前端）開始，比較容易上手。
和其他主軸的差異

什麼時候選 Python 本地工具？

需求 建議主軸
想快速試試 AI，不想安裝任何東西 主軸一 GAS + Gemini
要在課堂用轉盤、計時器等小工具 主軸三 Canvas 純前端
要用 LINE 接收訊息並自動回覆 主軸四 LINE Bot
要批次處理大量學生檔案，或自動化操作某個本機軟體 主軸五 Python 本地工具 ← 這裡
有資安顧慮，學生資料不能上傳雲端 主軸五 Python 本地工具 ← 這裡
優點與限制

什麼情況適合？什麼情況不適合？

✦ 適合的地方

  • 學生資料、成績、作品全部留在本機，不上傳任何雲端
  • 沒有月費或 API 費用（視工具而定）
  • 可以和本機軟體、瀏覽器、本地資料夾直接互動
  • 一次設定，之後重複使用，流程完全固定
  • 彈性最高，幾乎可以做任何自動化任務
  • 程式碼公開，可以依自己需求自由修改

△ 需要注意的地方

  • 需要安裝 Python，第一次有一定門檻
  • 工具只在你的電腦跑，電腦關掉就停
  • 出問題時需要看 log 除錯，比圖形介面複雜
  • 某些工具限 Windows（如涉及瀏覽器自動化）
  • 不適合需要隨時隨地存取的場景

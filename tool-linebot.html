LINE Bot
自動回覆系統

在學生和家長最熟悉的 LINE 裡，建立一個 AI 助理。自動回答問題、收作業、給回饋，讓溝通更有效率。

LINE Messaging API Google Apps Script Gemini AI 學生最熟悉
這個主軸在做什麼？

把 AI 放進學生的 LINE 裡

台灣幾乎人人都有 LINE，學生和家長也不例外。這條路線讓你建立一個 LINE Bot——一個可以自動回覆訊息的帳號。加入好友後，不管是學生問問題、家長詢問功課，或是老師想自動發送通知，都可以透過這個 Bot 完成。

結合 Gemini AI 之後，Bot 不只是固定回覆，而是能理解語意、根據情境給出適當的回應，甚至可以讀取圖片內容。

📱
學生不需要下載任何 App，不需要學習新工具。 他們只是在用 LINE，一個每天都在用的東西。
優點與限制

什麼情況適合？什麼情況不適合？

✦ 適合的地方

  • 學生和家長零學習成本，用既有的 LINE 就好
  • 跑在雲端，24 小時自動回覆
  • 可以接收文字和圖片，功能彈性高
  • 和 Google 行事曆、試算表深度整合
  • 電腦關掉也能繼續運作
  • 一個 Bot 可以同時服務多位使用者

△ 需要注意的地方

  • 初次設定較複雜，需要申請 LINE 開發者帳號
  • LINE Messaging API 免費版每月有訊息數限制
  • 需要 Gemini API Key（有免費額度）
  • 程式碼更新後需重新部署 GAS
  • 複雜對話邏輯需要較多程式設計
應用場景

LINE Bot 在教學上能做什麼

📅
行事曆助理

學生在 LINE 問問題，AI 根據你設定的知識庫回答

作業繳交

💬
家長通知

✅
出缺勤回報
學生傳訊息請假，自動記錄並回覆確認
🔔
考試提醒
設定重要日期，Bot 自動在前一天提醒所有學生

雲端郵件作業
自動評分

學生用 Gmail 繳交雲端資料夾連結。Apps Script 匯出信件與連結檢查結果，網頁工具計算成績並填入點名簿。

Apps Script 在老師的學校帳號執行，讀取作業信，並以未登入狀態開啟每個連結，確認是否為「知道連結的任何人均可檢視」。評分工具依評分標準扣分，依帳號與座號對應點名簿，寫入成績欄。

作業內容

第 1 週作業：雲端硬碟與 Gmail

發給學生的作業說明：

  • 登入 Google 雲端硬碟，在根目錄建立新資料夾。
  • 資料夾命名為「五年級資訊課-5XX-座號-姓名」。
  • 找一張北門校園風景照片，以「檔案上傳」方式上傳到資料夾。
  • 一般存取權設定為「知道連結的任何人均可檢視」，複製連結。
  • 登入 Gmail 撰寫新信，收件人填老師信箱。
  • 主旨格式：「5XX-座號-姓名-第1週作業」。
  • 內文包含稱呼（老師您好）、事由說明、資料夾連結、署名（學生某某敬上），寄出。

範例：

資料夾：五年級資訊課-501-01-張小明 主　旨：501-01-張小明-第1週作業 內　文：老師您好： 　　　　我要繳交第1週作業，照片是北門國小百齡樓。 　　　　https://drive.google.com/drive/folders/xxxxxxxx 　　　　學生張小明敬上
評分標準

滿分 20 分，逐項扣分

項目扣分判定方式
資料夾連結−3內文須有雲端資料夾連結，且未登入狀態可開啟
資料夾名稱−1符合「五年級資訊課-班級-座號-姓名」，班級、座號、姓名與點名簿一致
照片−1資料夾內至少一個圖片檔
主旨−1符合「班級-座號-姓名-第1週作業」
稱呼−1內文有「老師您好」或同義稱呼
事由說明−1去除連結、稱呼、署名後，仍有說明寄信原因的文字
署名−1內文有「敬上」

連結錯誤的情形（−3）

  • 內文無雲端連結，只有圖片或其他網站網址
  • 連結只放在主旨，內文沒有
  • 連結中間有空格或缺字，例如 https:// drive...
  • 連結指向單一檔案，不是資料夾
  • 未登入狀態無法開啟（權限為「限制」或「僅限校內」）

連結錯誤時看不到資料夾，資料夾名稱與照片兩項不再扣分。

✦ 放寬

  • 「第1週」「第一週」皆可，「週」「周」皆可
  • 座號補 0 可接受，例如 01
  • 「老師你好」「老師好」「親愛的老師」視為稱呼
  • 署名有「敬上」即可，不強制「學生」二字
  • 「啓／啟」「温／溫」視為同字

△ 從嚴

  • 多寫「座號」「姓名」字樣
  • 缺連字號，或用空格取代
  • 「5年級」取代「五年級」
  • 加上「」或句號
  • 姓名錯字
📌
多次寄信：同一寄件人只取最新兩封，保留分數較高者。學生可修正後重寄，舊錯誤不影響成績。
操作步驟

第一次設定約 10 分鐘，之後每次約 5 分鐘

📋
事前準備：收作業的學校 Google 帳號；點名簿 .xlsx，每個工作表一班，工作表名稱為班級（例如 501），第 1 列有「座號」「姓名」「帳號」三欄，帳號為學生信箱 @ 前的部分。
第一部分：匯出作業信
1

建立 Apps Script 專案

以收作業的學校帳號開啟 script.google.com，點「新專案」。

2

貼上程式並修改設定區

刪除預設內容，貼上 export_homework.gs 全文，修改開頭設定區：

const TEACHER_EMAIL = 'yourname@tmail.hc.edu.tw'; // 老師信箱 const START_DATE = '2026/09/01'; // 搜尋起始日 const KEYWORDS = '(作業 OR drive.google.com)'; // 關鍵字
3

執行並授權

上方函式選單選 exportHomework，按「執行」。第一次執行需授權 Gmail、雲端硬碟、試算表、外部連線。

出現「Google 尚未驗證這個應用程式」時，點「進階」→「前往（不安全）」。這是自己寫的程式，未送 Google 審核，屬正常情形。
4

下載 CSV

執行記錄顯示試算表網址。開啟試算表 →「檔案」→「下載」→「逗號分隔值 (.csv)」。

第二部分：計算成績
5

開啟評分工具，上傳兩個檔案

開啟 評分工具，選擇 CSV 與點名簿。

6

確認評分設定

預設值：滿分 20、連結 −3、其他 −1、取最新 2 封、第 1 週、資料夾開頭「五年級資訊課」、寫入 AA 欄、標題「雲端郵件」。依需要修改後按「計算成績」。

寫入欄已有其他資料時，自動改寫到右側第一個空白欄，不覆蓋原資料。欄位標題相同時直接覆寫，可重複執行。
7

檢查結果並下載

頁面列出每班寫入人數與每位學生的扣分原因。按「下載已填成績的點名簿」取得新檔；「下載評分明細」取得最終成績與逐封評分。

建議抽查扣分較多的學生，確認判定合理。點名簿查無帳號的寄件人會顯示在提示訊息。
優點與限制

適用範圍

✦ 優點

  • 權限檢查以未登入狀態實測，結果與學生設定一致
  • 評分標準固定，各班一致
  • 每項扣分附原因，可回覆學生
  • 不需安裝軟體，瀏覽器即可使用
  • 學生資料不上傳第三方伺服器

△ 限制

  • 無法判斷照片內容是否為北門校園，只檢查有無圖片
  • 事由說明以關鍵字判斷，建議人工抽查
  • 只檢查內文第一個雲端連結
  • 點名簿帳號錯誤時無法對應
  • Apps Script 單次執行上限 6 分鐘，信件過多時需縮小日期範圍
常見問題

疑難排解

執行後找不到任何信件

確認以收作業的帳號執行，並檢查 TEACHER_EMAIL 與 START_DATE。可先在 Gmail 搜尋列輸入 to:老師信箱 after:2026/09/01 驗證。

「匿名可開啟」全部顯示「否」

抽一個連結以無痕視窗開啟。可開啟表示檢查程式受阻，確認第一次執行時已授權「連線到外部服務」；無法開啟表示學生權限設定確實有誤。

學生說已設定公開，仍被扣連結分數

常見原因：選成「僅限校內使用者」、分享的是照片檔而非資料夾、連結複製不完整。請學生改正後重寄，系統取最新兩封中較高分者。

點名簿有學生沒有成績

未寄信，或寄件信箱 @ 前的帳號與點名簿「帳號」欄不同。帳號比對不分大小寫。

下載的點名簿格式跑掉

一般儲存格格式、欄寬、日期會保留；巨集、樞紐分析表、圖表不支援。先保留原檔備份。

學生資料處理方式

🔒
成績計算在老師的瀏覽器完成。評分工具為純前端頁面，CSV 與點名簿不上傳任何伺服器，關閉頁面即清除。

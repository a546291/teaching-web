主軸一 · GAS + Gemini 對話式 AI

LINE 行事曆
AI 助理

在 LINE 傳一句話，或拍一張活動傳單，AI 幫你自動把行程加進 Google 行事曆，還會提醒你有沒有時間衝突。

Google Apps Script Gemini API LINE Messaging API 免費額度可用
這是什麼？

跟 LINE 說一聲，行程自己跑進去

這個工具讓你把 LINE 變成行事曆的入口。不需要打開 Google 行事曆、不需要手動輸入時間——你只要在 LINE 裡傳一段話，例如「下週三下午兩點，學年會議，在圖書館」，或者拍一張家長通知單的照片傳過去，AI 就會自動解析時間、地點，幫你建好行程，還會告訴你那個時段有沒有跟其他行程衝突。

💬
實際示範： 傳送「6/15 早上九點，畢業典禮，在大禮堂，記得提前半小時到」，AI 會建立「畢業典禮」行程、設定 9:00 開始，並在說明欄注記「提前半小時到」，還會自動設定 30 分鐘前通知。

怎麼運作的？

三個工具串在一起

這個系統由三個免費工具組成，各自負責不同的事：

你在 LINE
傳訊息或照片
→
Google Apps Script
接收並轉交給 AI
→
Gemini AI
解析時間地點
→
Google 行事曆
自動建立行程
LINE Messaging API（接收訊息）
Google Apps Script（中間樞紐）
Gemini 2.0 Flash（AI 解析）
Google 行事曆（儲存行程）
🤔
Google Apps Script 是什麼？ 就像 Google 試算表裡可以寫公式一樣，Apps Script 讓你在 Google 的雲端環境裡寫一小段程式，完全不需要架設自己的伺服器。這個工具幫你把 LINE、Gemini、行事曆三個服務串起來。
優點與限制

什麼情況適合？什麼情況不適合？

✦ 適合的地方

  • 在最熟悉的 LINE 介面操作，不需學新工具
  • 可以傳照片——拍下家長通知單、活動傳單，AI 自動解讀
  • 自動偵測行程衝突，避免雙重預約
  • AI 懂得區分「活動時間」和「報名截止日」，不會搞混
  • 每次建立行程自動設定 30 分鐘前通知
  • 使用 Google 免費服務，無額外費用（Gemini 有免費額度）
  • 紀錄每次使用的 AI 費用，清楚掌握成本

△ 需要注意的地方

  • 初次設定需要約 30–45 分鐘，步驟較多
  • 需要申請 LINE 開發者帳號（免費，但要填資料）
  • 需要申請 Gemini API Key（免費額度每天有限制）
  • AI 偶爾會解析錯誤，建議確認行事曆再離開
  • 無法刪除或修改已建立的行程（只能新增）

怎麼設定？

一步一步來，不需要急

整個設定分為四個部分，每個部分都可以休息再繼續。建議第一次先在有網路的環境進行，大約需要 30–45 分鐘。

📋
開始前需要準備： Google 帳號（免費）、LINE 帳號、電腦瀏覽器（Chrome 最佳）

第一部分：取得 Gemini API Key

1

前往 Google AI Studio

在瀏覽器開啟 aistudio.google.com，用 Google 帳號登入。

Google AI Studio 首頁截圖（待補）
2

建立 API Key

點左側選單的 Get API Key → Create API Key，選擇建立新的 Google Cloud 專案，複製產生的 Key（一長串字母數字）。

這個 Key 很重要，等一下會用到，先存到記事本。每天免費額度大約可以發送數百則訊息，一般教師使用完全足夠。
取得 API Key 截圖（待補）

第二部分：建立 LINE Bot

3

前往 LINE Developers

開啟 developers.line.biz，用你的 LINE 帳號登入，點右上角 Console。

LINE Developers 登入截圖（待補）
4

建立 Provider 和 Channel

點 Create a new provider，輸入你的名字或學校名稱，按 Create。接著點 Create a Messaging API channel，填入：

Channel name行事曆助理（或任意名稱）
CategoryEducation
SubcategoryElementary/Junior High School
5

取得 Channel Access Token

建立好之後，點 Messaging API 頁籤，拉到最底下，點 Issue 產生 Channel Access Token，複製這個 Token 存到記事本。

同一頁面也能找到 QR Code，用手機掃描就能加這個 Bot 為好友，之後就是傳訊息給它來新增行程。
Channel Access Token 截圖（待補）

第三部分：設定 Google Apps Script

6

建立 Google 試算表（記錄用）

開啟 sheets.google.com 建立一個新的空白試算表，複製網址列中間那一長串文字（試算表 ID），存到記事本。

網址格式：docs.google.com/spreadsheets/d/這裡就是ID/edit
7

建立 Apps Script 專案

開啟 script.google.com，點 新增專案，把預設的空白程式碼全部刪除。

Apps Script 新增專案截圖（待補）
8

貼上程式碼並填入你的金鑰

前往 GitHub repo 複製 Code.gs 的完整內容，貼到 Apps Script 編輯器，然後修改最上方三行：

// 把引號裡的文字換成你自己的 const LINE_ACCESS_TOKEN = '貼上你的 LINE Channel Access Token'; const GEMINI_API_KEY = '貼上你的 Gemini API Key'; const SPREADSHEET_ID = '貼上你的試算表 ID';
⚠️
填完之後，不要把這個 Apps Script 分享給別人，裡面有你的 API Key。
9

初始化試算表標題

在 Apps Script 上方函式選單選擇 setupSheet，點執行（▶），系統會要求你授權存取 Google 試算表，點 允許 即可。

執行一次就好，這個步驟幫你在試算表第一列建立「時間、使用者輸入、建立行程標題…」等欄位標題。
10

部署為 Web App

點右上角 部署 → 新增部署，設定如下：

類型網頁應用程式
執行身份我（你的 Google 帳號）
存取權任何人（LINE 平台需要能連進來）

點 部署，複製產生的網址（Web App URL）存到記事本。

Apps Script 部署截圖（待補）

第四部分：把 Bot 和 Script 串起來

11

設定 LINE Webhook

回到 LINE Developers Console，點 Messaging API 頁籤，找到 Webhook URL 欄位，貼上剛才複製的 Web App URL，點 Update，再點 Verify。

如果 Verify 顯示成功（Success），代表 LINE 和你的 Script 已經成功串聯。如果失敗，請確認 Web App 的存取權限是否設為「任何人」。
LINE Webhook 設定截圖（待補）
12

關閉自動回覆、開啟 Webhook

同一頁面，確認：

✓ Use webhook：開啟
✕ Auto-reply messages：關閉（否則會干擾 AI 回覆）
13

測試！傳第一則訊息給 Bot

用手機掃描 QR Code 加 Bot 為好友，傳一則測試訊息：

「明天下午三點，辦公室開會」

Bot 應該會回覆建立成功的訊息，並在你的 Google 行事曆出現新行程。

🎉
如果成功收到回覆，恭喜你！設定完成。之後只要跟 Bot 說，行程就會自動存進去。
遇到問題？

常見疑問

Bot 沒有回覆怎麼辦？

最常見的原因：① Webhook URL 沒有貼正確、② 自動回覆沒有關閉、③ API Key 或 Token 填錯。可以到 Apps Script 點「執行記錄」查看錯誤訊息。

時間被解析成明年怎麼辦？

AI 依賴當下時間做判斷，描述時盡量說「本週五」、「5/30」等明確日期，比「下週五」更準確。發現問題直接到 Google 行事曆手動修改就好。

Gemini 免費額度夠用嗎？

Gemini 2.0 Flash 目前有每日免費使用額度，一般老師一天新增幾個行程完全足夠。試算表也會幫你記錄每次的費用，可以自己觀察。

可以讓同事一起用嗎？

可以，你可以在 LINE Bot 加入多位好友，他們傳的訊息都會建立到你的行事曆。若要讓每個人管理自己的行事曆，需要各自設定一套，程式碼可以照著本文件操作。

資安確認

這個工具安全嗎？

✓ API Key 和 Token 只存在 Apps Script，不會出現在公開程式碼
✓ GitHub repo 上的程式碼為佔位符，不包含任何真實金鑰
✓ 不收集任何學生個人資料，僅處理老師自己傳入的訊息
✓ Google Apps Script 部署在 Google 官方雲端，安全可靠
△ GAS 部署設為「任何人可存取」—— 這是 LINE Webhook 的必要設定，屬正常架構，並非安全漏洞
△ 建議：改用 Script Properties 儲存金鑰（進階選項，見下方說明）
🔒
進階：更安全的金鑰儲存方式
在 Apps Script 點 專案設定 → 指令碼屬性，新增三個屬性：LINE_TOKEN、GEMINI_KEY、SHEET_ID，程式碼最上方三行改為：
const LINE_ACCESS_TOKEN = PropertiesService.getScriptProperties().getProperty('LINE_TOKEN'); const GEMINI_API_KEY = PropertiesService.getScriptProperties().getProperty('GEMINI_KEY'); const SPREADSHEET_ID = PropertiesService.getScriptProperties().getProperty('SHEET_ID');
這樣即使你分享程式碼給別人，金鑰也不會外洩。
